# 💗 A Little Apology Website

A romantic animated apology microsite made with plain HTML, CSS and JavaScript.

## ✨ Customize it

Open `script.js`.

At the very top you'll find:

```js
const LOVE = {
  herName: "My Love",
  yourName: "your idiot",
  extraNames: []
};
```

Change those before uploading.

### Optional
You can also edit the actual apology text in `index.html` if you want to make it more personal.

## 🚀 GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. GitHub will give you the website URL.

No framework, npm, build step, or server is required.

## 💕 Tip

Before sending it, replace the generic parts with one or two memories/jokes that are specifically yours. That will make it feel much more genuine.
